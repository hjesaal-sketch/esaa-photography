# ESAÁ PHOTOGRAPHY

Sitio web de fotografía en homenaje a Henry Joe Esaá Francés y portafolio de Henry Jorge Esaá Lazo.

## Características

- Modo oscuro/claro con persistencia
- Menú hamburguesa responsive
- Carrusel con fade automático en el Hero
- Galería con fade-in escalonado
- Diseño minimalista en blanco, gris, negro y verde esmeralda

## Tecnologías

- HTML5
- CSS3 (Variables CSS, Flexbox, Grid, Animaciones)
- JavaScript (Intersection Observer, Event Listeners)

## Despliegue

El sitio está desplegado en Vercel:
